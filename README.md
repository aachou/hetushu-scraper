# hetushu-scraper

把[和图书](https://www.hetushu.com)上的小说一键下载为 EPUB 电子书。

```bash
uv sync && uv run main.py 12345
```

> 书籍 ID 从页面 URL 获取：`https://www.hetushu.com/book/12345/index.html` → `12345`
>
> 一次可传多本（空格分隔），会一本一本地串行下载：
>
> ```bash
> uv run main.py 12345 67890 11111
> ```
>
> 首次运行会自动下载约 200MB Chromium 内核，稍等片刻。

---

## 🎮 所有参数

| 参数 | 作用 | 默认值 |
|------|------|--------|
| `book_id` | 书籍 ID，可多个（空格分隔）；省略则交互输入 | — |
| `-o` / `--output` | 输出目录或 `.epub` 路径 | 当前目录 |
| `--headed` | 显示浏览器窗口 | 无头（不显示） |
| `--concurrency` / `-c` | 并发抓取的页面数（复用页面） | `8` |
| `--delay` / `-d` | 每次请求前等待秒数 | `0`（不限速） |
| `--max-retries` | 失败重试次数 | `3` |
| `--timeout` | 页面加载超时（毫秒） | `30000` |
| `--no-cache` | 忽略已有缓存并重新下载，生成 EPUB 后清除缓存 | 保留缓存 |
| `--verbose` / `-v` | 打印详细请求日志 | 关闭 |

**常用组合：**`--concurrency 1 --delay 2` → 每 2 秒一章，对服务器最友好。

## ✨ 功能一览

- 🕵️ **反爬无忧** — CloakBrowser 模拟真人、独立随机 UA，自动还原打乱的段落并剔除水印垃圾
- ⚡ **快而稳** — 页面池并发，失败自动重试，正文就绪即抓、不空等
- 🔁 **断点续传** — 中断不慌，缓存保留，下次秒续
- 📚 **批量串行** — 一次传入多本书 ID，逐本下载
- 📦 **EPUB 输出** — 带章节目录，Kindle / Apple Books / Calibre 通用
- 🗃️ **缓存持久化** — 默认保留；加 `--no-cache` 忽略旧缓存、用完即删
- 🪟 **Windows 友好** — 不乱码、不崩溃

## ❓ 常见问题

**默认有没有浏览器窗口？**

默认无头，浏览器在后台静默工作。想看运行过程加 `--headed` 即可。

**网络不好总失败？**

脚本会自动重试。还不行就加 `--max-retries 5 --timeout 60000` 给更多耐心。最终失败章节会被跳过，不影响已成功的。

**下载一半断了，要重来吗？**

不用。再跑一次会自动跳过已缓存章节，只下载缺失的。想彻底重新下载，删掉 `.chapter_cache/` 目录或加 `--no-cache`。
